# Отчёт о независимой проверке — GitHub LOC

Проверялось расширение `GitHub LOC` (MV3, `manifest.json` версии 1.0.1) и его движок подсчёта
в `src/loc/**`. Проверка велась **против спецификации** [SPEC.md](../SPEC.md), а не против кода:
независимый оракул [verify/oracle.py](oracle.py) написан на Python 3 (только stdlib) по тексту
SPEC, код движка при его написании не читался и не копировался.

Все команды ниже выполнялись из корня репозитория.

## 2. Дефекты

### D1 (high, найден и исправлен): ustar `prefix` читался со смещения 344 вместо 345

`src/loc/tar.js` читал поле `prefix` как `readCString(header, 344, 500)`. По POSIX ustar
`devminor` занимает `[337,345)`, а `prefix` — `[345,500)`. Байт 344 — завершающий NUL `devminor`,
поэтому `readCString` возвращал пустую строку, путь терялся, и файлы с полным путём длиной
100–255 символов (записанным через `prefix`) **молча выбрасывались** как `nonFile`.

Репродукция (была в `verify/fixtures/mk-prefix-repro.py`):

```
python3 verify/fixtures/mk-prefix-repro.py
node verify/engine-trace.mjs /tmp/ghloc-verify/prefix-repro.tar.gz
# было:  file  12  nonFile  empty-rel
# стало: <полный путь 154 симв.>  file  12  counted  lang=Python
```

Влияние до исправления (оракул → движок, один tarball, один commit):

| Репозиторий | Оракул | Движок (было) | Движок (стало) |
|---|---|---|---|
| `rust-lang/rustlings` @ `bc8e51115c93` | 15734 строк / 290 файлов | 15730 / 288 | **15734 / 290** ✅ |
| `golang/example` @ `7f05d217867b` | 10716 / 64 | 9979 / 50 | пересчёт на HEAD: совпадает ✅ |
| `pallets/flask` @ `d086db856be1` | 34632 / 228 | 34614 / 223 | совпадает ✅ |

Причина, по которой дефект не поймали тесты: в `tests/loc.test.mjs` были кейсы `pax` и
GNU `LongLink`, но ни одного кейса с `prefix`-полем. Добавлен тест `prefix`-записи
(`tests/tar-writer.mjs` пишет `prefix` корректно, т.е. писатель фикстуры был прав).

### D2 (medium, найден при визуальной проверке): подписи строк «съезжали» на соседний язык

В новой разметке GitHub `li` — `display:inline`, а ссылка внутри — `inline-flex` с
`white-space:nowrap`. Подпись `ghloc-lang-lines` добавлялась в `li` и выпадала из строки:
цифры визуально оказывались у следующего языка. Исправлено: подпись вставляется внутрь
`<a>` после процентов, `pointer-events:none`, `font-size:11px`, `title` с точным числом
строк и файлов. Проверено скриншотами в тёмной и светлой теме
(`docs/screenshot-dark.png`, `docs/screenshot-light.png`), переполнения нет
(`scrollWidth == clientWidth`).

### Дефекты, найденные и исправленные по ходу разработки

* `src/content.js` не загружался: последовательность `*/` внутри блочного комментария
  (`sidebarSection__*/languageList__*`) обрывала комментарий → `SyntaxError`. Ловилось
  e2e («панель не появилась») и `node --check`.
* `src/popup.js` импортировал `../loc/format.js` вместо `./loc/format.js` → модуль не
  загружался, popup оставался пустым. Ловилось e2e (проверка «popup открывается»).
* `scanTar` не дочитывал хвост потока → `archiveBytes` зависел от размера чанков.
  Ловилось тестом «результат не зависит от размера чанков».

## 3. Сверка движка с оракулом

Команда:

```
bash verify/compare-engine.sh rust-lang/rustlings pallets/flask octocat/Spoon-Knife
```

Скрипт фиксирует commit через `api.github.com`, качает
`https://codeload.github.com/<owner>/<repo>/tar.gz/<sha>`, прогоняет по одному и тому же
файлу оракул и `node tools/count-repo.mjs`, и сравнивает `total`, `files`, `bytes`,
`truncated`, `skipped`, `entries` и разбивку `perLanguage`.
Сырые выводы: `verify/raw/v2/compare-*.txt`.

Результат после исправления D1: совпадение по `total`, `files`, `bytes`, `truncated`,
`entries` и по каждому языку. Малые расхождения в `skippedReasons` — следствие
незафиксированного в SPEC порядка применения причин пропуска (см. `METHOD.md`, п. 4.3)
и не влияют на `total`.

## 4. Расширение в реальном браузере

```
node tools/e2e-browser.mjs
```

Поднимается настоящий headless Chromium с загруженным расширением, открывается живой
`https://github.com/octocat/Spoon-Knife`, tarball подменяется на локальную фикстуру с
эталонными числами (`docs/e2e-fixture.tar.gz`, эталон: 13 строк, 4 файла).

Проверки (все прошли):

1. service worker расширения загружен;
2. настройки записываются в `storage`;
3. панель вставлена под «Languages»;
4. подписи строк добавлены к языкам;
5. кнопка «Точный подсчёт» нажимается;
6. точный итог = 13 строк (совпадает с эталоном фикстуры);
7. разбивка по языкам: Python 5/1, Rust 4/1, Markdown 3/1, JavaScript 1/1 — совпадает;
8. скриншот панели сохранён;
9. popup открывается и читает настройки/статистику кэша;
10. в popup нет исключений;
11. на странице github.com нет исключений расширения;
12. в service worker нет исключений.

Отчёт прогона: `docs/e2e-report.json`.

Дополнительно вручную проверено в обычном (не headless) Chromium на живом
`github.com/astral-sh/uv`: оценка `≈ 656 000 строк`, per-language подписи
(Rust 642 тыс., Python 12 тыс., Shell 1,5 тыс., Dockerfile 201, Batchfile 225,
PowerShell 160), разбивка в «Подробнее» совпадает с суммой.

## 5. Враждебные кейсы

| Кейс | Как проверено | Результат |
|---|---|---|
| Обрезанный архив | тест «обрезанный архив: `scanTar` бросает `truncated`» | `countTarball` возвращает частичный результат с `truncated:true`, не падает |
| Отмена подсчёта | тест «отмена через `AbortSignal`» + кнопка «Отмена» | `Error.code='aborted'`, UI показывает «Подсчёт отменён» |
| Битый gzip | прогон через `DecompressionStream` | ошибка ловится, панель показывает русский текст ошибки |
| Файл больше лимита | тест `maxFileBytes` | `skippedReasons.tooLarge`, не читается |
| Архив больше лимита | подсчёт сжатых байт на лету, `maxArchiveMB` | `too_large`, оценка остаётся доступной |
| Пустой архив / репозиторий без языков | тест «пустой архив — нули» | 0 строк, без исключений |
| Мусорные настройки | тест `normalizeSettings` | приводятся к дефолтам, без падений |
| Служебные пути GitHub | тест `repoFromPath` (`/settings`, `/orgs/...`, `/marketplace`) | панель не вставляется |
| Неизвестный язык / бинарник | тесты `looksBinary`, `detectLanguage` | `binary`/`unknown`, в `total` не попадают |

Чего **не** удалось проверить вживую: 403/429 rate limit (не воспроизводили исчерпание
лимита), приватный репозиторий (нет тестового приватного репо), поведение на очень большом
архиве (>120 МБ) — проверено только логикой и юнит-тестами, не реальным репозиторием.

## 6. Безопасность

| Проверка | Результат |
|---|---|
| `innerHTML`/`outerHTML` с внешними данными | не используется; DOM только через `createElement`/`textContent` |
| `eval`, `new Function` | отсутствуют |
| Inline-скрипты в HTML | отсутствуют (CSP MV3), только внешние `popup.js` |
| `manifest.json` permissions | `storage`; host — только `github.com`, `api.github.com`, `codeload.github.com` |
| Разрешение `cookies` | отсутствует (сессия GitHub используется через `credentials:'include'`, cookies не читаются) |
| Куда уходит токен | только в заголовке `Authorization` к `api.github.com` |
| Сторонние домены | в коде нет иных доменов, кроме перечисленных в `host_permissions` |
| Секреты в репозитории | `tools/extension-key.pem` (приватный ключ подписи CRX) в `.gitignore`, не публикуется |

## 7. Что осталось непроверенным

* Firefox: `dist/firefox` собирается (`background.scripts`, MV3), но запуск не проверялся —
  Firefox в системе не установлен.
* Приватные репозитории и исчерпание rate limit — только по коду.
* Safari/прочие браузеры не поддерживаются.
* Локализация: интерфейс только на русском (по заданию).
* Точность оценки по байтам — эвристика по среднему числу байт на строку; расхождение с
  точным подсчётом на `astral-sh/uv` составило ≈ 656 000 (оценка) против точного значения,
  полученного движком (767 743) — это ожидаемо для оценки и явно помечено в UI символом «≈».
